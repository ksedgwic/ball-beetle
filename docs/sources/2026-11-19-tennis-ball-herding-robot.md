# Tennis ball herding robot

A conversation between Ken and Claude, an AI assistant, on 2026-11-19,
about a name for the project.  It is kept here as source material for
the outlines.

The assistant's statements about other products and about which names
are in use have not been checked.  The wording is unchanged; only the
line breaks differ.

## 1. Ken

I'm looking for a good project name for the following device:

* driving robot that "herds" tennis balls on a tennis court
* open source project, currently one other interested person
* maybe uses DonkeyCar
* goal is to have it push errant tennis balls to a good spot on the
  side of the court

Here are some ideas I had:

* ball-beetle - maybe it has a hard shell to protect it eventually
* scarab-something

## 2. Claude

Your scarab instinct is a good one, because dung beetles really do
push balls around. Here's a mix built on that and a few other angles.

**Scarab / beetle**
- **Khepri**: the Egyptian scarab god, who rolled the sun across the
  sky the way a dung beetle rolls its ball. It's short, unusual, sounds
  good, and the backstory explains itself in one sentence in a README.
- **ball-beetle**: friendly and literal. It does sound a bit generic.
- **Rollie**: the slang name for pill bugs, which also have a hard
  shell. It's cute and easy to say, but probably not unique.
- **dungbot**: the most accurate name and the most likely to get a
  laugh. Whether it works depends on whether you want the project
  taken seriously.

**Herding dog** (this fits what the robot actually does: herding, not
collecting)
- **Kelpie**: an Australian herding dog. It's one short word, easy to
  spell, and fairly rare as a software name. This is my favorite
  non-beetle option.
- **Heeler** or **Collie**: same idea. "Heeler" has a nice double
  meaning because the robot nips at stray balls.

**Tennis wordplay**
- **Deuce** or **Let**: very short, but common enough that you'll run
  into name collisions.
- **Fuzzherder**: descriptive and a little silly, and you'd almost
  certainly be able to get the name.

**DonkeyCar connection**
- **Burro** or **Mule**: a small working animal pushing things around,
  which nods to DonkeyCar without copying its name.

**Myth**
- **Sisyphus**: eternally pushing balls is very on the nose. But
  Sisyphus Industries already uses the name for its kinetic sand
  tables, and the joke implies the job never ends.

There's also already a commercial ball-collecting robot called
Tennibot, so I'd avoid anything that starts with "Tenni-".

My picks are **Khepri** if you want to keep the beetle and shell idea,
or **Kelpie** if you want the name to describe what the robot does.
Before you commit, search GitHub and PyPI for the name, and check
whether the domain or org handle you'd want is free. With only two
people on the project so far, renaming later is cheap, but it's easier
still to get it right now.

# ball-beetle

A hobby project to build a small driving robot that clears stray
tennis balls from a tennis court.  It pushes them to a spot at the
side of the court, or picks them up; that choice is open.

"ball-beetle" is a working name.  The project is at the research
stage; there is no code yet.  Ideas and the research on hardware and
software components are kept as outlines in
[docs/](./docs/README.md).
